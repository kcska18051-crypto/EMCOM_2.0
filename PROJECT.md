# ЭМКОМ 2.0 — интерактивный прототип

## Назначение

Статический кликабельный HTML-прототип корпоративного сайта ЭМКОМ на основе структуры шаблона «Аспро: Корпоративный сайт 3.0». Прототип фиксирует смысловые блоки, состав страниц, навигацию и мобильную адаптацию. Изображения намеренно заменены серыми прямоугольниками, пиктограммы — серыми кругами, а неизвестный контент — рыбным текстом.

## Реализованные разделы

- Главная страница: шапка, главный баннер, фичеры, узкий баннер, решения, блок о компании, кейсы, производственные мощности, этапы работы, форма обратной связи и подвал.
- О компании: основная страница, история, партнёры, сертификаты/лицензии и команда.
- Решения: список, второй уровень автономного и резервного электроснабжения, детальная страница дизельных электростанций.
- Услуги: список и детальная страница предпроектного обследования.
- Кейсы: список и детальная страница проекта 1.
- Производство.
- База знаний: список статей и детальная страница статьи 1.
- Контакты с двумя адресами и серой зоной карты.

## Страница «Команда»

- В списке шесть демонстрационных карточек.
- На десктопе выводятся три карточки в ряд, на планшете — две, на мобильном — одна.
- Все фотографии заменены серыми прямоугольниками.
- Используются подписи «Фамилия имя отчество» и «Должность» без реальных данных.
- Только первая карточка ведёт на демонстрационную детальную страницу.
- Детальная страница содержит должность, телефон, e-mail, серый портрет и два абзаца рыбного текста.
- Блоки услуг, проектов, отзывов, социальных сетей, кнопка сообщения и форма обратной связи не используются.

## Навигация и адаптив

- Основная шапка едина для всех готовых страниц.
- Кнопка «Написать нам» открывает общее модальное окно на каждой готовой странице.
- Пункт «О компании» содержит выпадающее меню на десктопе; на мобильных устройствах используется бургер без десктопного выпадающего списка.
- Порядок подразделов компании: «О компании», «Команда», «История компании», «Партнёры», «Сертификаты/лицензии», «Реквизиты».
- Страница «Команда» связана с выпадающим меню шапки, боковым меню и мобильной навигацией раздела компании.
- Относительные ссылки рассчитаны для публикации в подпапке GitHub Pages.

## Модальная форма «Написать нам»

- Обязательные поля: имя, телефон, организация, электронная почта и описание проекта.
- Согласие на условия обработки персональных данных обязательно.
- Вложение файла необязательно; рядом перечислены подходящие материалы: ТЗ, спецификация, чертёж, опросный лист и другие материалы.
- После локальной демонстрационной отправки показывается согласованный экран благодарности; данные никуда не передаются.
- Окно закрывается крестиком, кликом по затемнению и клавишей Escape. На мобильных устройствах форма занимает весь экран и прокручивается.

## Технологии и структура

- HTML5, CSS Grid/Flexbox и небольшой JavaScript для шапки.
- Общие стили: `assets/css/prototype.css`.
- Поведение шапки: `assets/js/header.js`.
- Автоматические проверки: Node.js `node:test`, каталог `tests/`.
- Запуск тестов: `npm test`.

## Правила дальнейшей работы

1. Пользователь полностью задаёт состав страницы и контент; новые смысловые блоки не додумываются самостоятельно.
2. Общий визуал и мобильный адаптив сверяются с соответствующей страницей шаблона Аспро.
3. Неизвестные изображения и иконки показываются серыми плейсхолдерами.
4. Неизвестный текст заменяется согласованным рыбным текстом.
5. Интерактивными делаются только явно согласованные ссылки и элементы.
6. После изменения страницы обновляются тесты, проверяются относительные ссылки, мобильная версия и отсутствие горизонтального переполнения.

## Текущее состояние

Прототип содержит все согласованные страницы. Во всех шапках работает единая демонстрационная модальная форма «Написать нам».
