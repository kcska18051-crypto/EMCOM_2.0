# Модальная форма «Оставить заявку»

## Назначение

Добавить вторую демонстрационную форму обратной связи для кнопки «Получить предварительный расчёт» на трёх страницах прототипа:

- детальная страница решения «Дизельные электростанции»;
- детальная страница услуги «Предпроектное обследование»;
- страница «Производство».

Существующая модальная форма «Написать нам» и большая форма на главной странице не изменяются.

## Архитектура

Вторая форма реализуется как самостоятельный общий модальный компонент в `assets/js/header.js`. Разметка создаётся JavaScript один раз на каждой странице, где присутствует кнопка с маркером открытия формы. Такой подход сохраняет единое поведение на трёх страницах и исключает дублирование разметки.

Стили добавляются в общий файл `assets/css/prototype.css`. Новое окно использует существующую визуальную систему модальной формы: белая панель, затемнённый фон, серые поля, тёмный текст и синяя кнопка отправки.

## Точка входа

Текущий визуальный элемент «Получить предварительный расчёт» заменяется на кнопку с тем же текстом. Кнопка получает отдельный атрибут-маркер для открытия формы «Оставить заявку».

На странице производства и на двух детальных страницах используется один и тот же компонент. Остальные страницы не получают эту кнопку автоматически.

## Состав формы

Заголовок: «Оставить заявку».

Обязательные элементы:

- поле «Ваше имя»;
- поле «Телефон»;
- согласие на условия обработки персональных данных.

Необязательные элементы:

- поле «Комментарий»;
- прикрепление файла.

Кнопка отправки: «Отправить».

После локальной демонстрационной отправки вместо формы показывается текст:

> Спасибо! Заявка отправлена. Специалист ЭМКОМ свяжется с вами в течение рабочего дня.

Данные и выбранный файл не передаются на сервер.

## Поведение

- Окно открывается по кнопке «Получить предварительный расчёт».
- При открытии фокус переходит в поле «Ваше имя».
- Отправка невозможна без имени, телефона и согласия.
- Имя выбранного файла показывается внутри формы.
- После корректного заполнения показывается экран благодарности.
- Окно закрывается крестиком, кликом по затемнению или клавишей Escape.
- После закрытия фокус возвращается на кнопку открытия.
- После закрытия экрана благодарности форма очищается и возвращается в исходное состояние.

## Адаптив

На десктопе окно выводится по центру поверх затемнения и визуально соответствует модальной форме шаблона Аспро. На мобильных устройствах окно занимает весь экран, содержимое прокручивается, а кнопка отправки занимает доступную ширину.

## Проверка

Автоматические тесты проверяют:

- наличие кнопки на трёх согласованных страницах;
- отсутствие маркера второй формы на остальных страницах;
- точный заголовок и состав полей;
- обязательность имени, телефона и согласия;
- необязательность комментария и файла;
- точный текст успешной отправки;
- открытие, закрытие и переключение на экран благодарности;
- десктопные и мобильные стили.

После публикации выполняется браузерная проверка на десктопном и мобильном размерах экрана.
