# Адаптивная шапка — дизайн

## Десктоп

Шапка представляет собой одну белую строку поверх главного баннера. Слева расположен логотип ЭМКОМ, затем пункты «О компании», «Решения», «Услуги», «Кейсы», «Производство», «База знаний», «Контакты», справа — выделенный элемент «Форма обратной связи». Выпадающий список «О компании» сохраняется.

## Мобильная версия

По образцу Aspro Corporate 3.0 отображается компактная строка высотой 62 пикселя: бургер слева и логотип рядом. Основная навигация скрыта и раскрывается вертикальной панелью под шапкой. В панели находятся все семь разделов и ссылка «Форма обратной связи». Переноса горизонтального меню на несколько строк нет.

## Поведение

Бургер синхронизирует `aria-expanded` и класс открытого состояния панели. Escape, клик вне шапки и переход на десктопную ширину закрывают мобильное меню. Ссылка формы ведёт к существующему блоку обратной связи.
