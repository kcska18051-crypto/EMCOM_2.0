# ЭМКОМ_2.0 — дизайн кликабельного прототипа

## Цель

Создать публичный кликабельный HTML-прототип корпоративного сайта на основе смысловых блоков шаблона «Аспро: Корпоративный сайт 3.0». Прототип используется как рабочая схема для аналитики, согласования структуры, разработки и последующей подготовки проектной технической документации.

## Границы первой итерации

- До 20 шаблонов страниц.
- Страницы добавляются постепенно после отдельного обсуждения каждой страницы или блока.
- Используются существующие типы и композиции блоков Aspro; новые продуктовые сценарии не проектируются без отдельного запроса.
- Воспроизводятся структура, смысл, состав элементов и переходы, но не исходный код и не финальный визуальный дизайн шаблона.
- Изображения заменяются нейтральными серыми заглушками.
- Инструменты автоматической подготовки контента для клиента не входят в первую итерацию.

## Представление

- Отображаемое название проекта: **ЭМКОМ_2.0**.
- Техническое имя GitHub-репозитория: `EMCOM_2.0`.
- Репозиторий и опубликованный GitHub Pages-сайт публичные.
- Интерфейс монохромный и намеренно схематичный.
- Подписи показывают назначение блоков и элементов, не имитируя финальные маркетинговые тексты.

## Архитектура

- Статический HTML, CSS и минимальный JavaScript без серверной части.
- Стартовая страница служит реестром доступных прототипов.
- Каждая согласованная страница имеет отдельный адрес.
- Общие элементы — шапка, навигация, подвал и базовые стили блоков — переиспользуются.
- Навигация, кнопки и другие оговорённые элементы работают, чтобы пользователь мог пройти основной сценарий.
- Структура файлов и названия блоков остаются понятными разработчику без изучения внутренней реализации.

## Рабочий процесс

1. Пользователь передаёт ссылку, скриншот, название или описание блока Aspro.
2. Совместно уточняются состав, последовательность и переходы страницы.
3. После подтверждения страница или блок добавляется в прототип.
4. Изменение проверяется локально и публикуется через GitHub Pages.
5. Ссылка на обновлённый прототип используется для следующей итерации и согласования.

## Проверка качества

- Все внутренние ссылки открывают ожидаемые страницы или состояния.
- Страница остаётся читаемой на типовом настольном и мобильном экране.
- Блоки визуально различимы и подписаны.
- В прототипе отсутствуют случайные финальные изображения и несогласованный контент.
- Публичная версия соответствует последнему подтверждённому состоянию основной ветки.

## Отложенная итерация

После завершения структуры страниц отдельно проектируется передача прототипа клиенту для подготовки текстов, изображений и других материалов с помощью ChatGPT. Эта часть может включать карту контента и машиночитаемое описание страниц, но не влияет на первую версию прототипа.
