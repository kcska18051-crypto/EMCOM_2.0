# Корректировка контента страницы «Производство»

## Цель

Упростить основную область страницы «Производство»: удалить боковое меню и показать возможность размещения изображения непосредственно внутри текстового материала.

## Неизменяемые элементы

- Главный серый баннер.
- Хлебные крошки «Главная — Производство».
- Заголовок «Производство».
- Некликабельная кнопка «Получить предварительный расчёт».
- Общая шапка, мобильное бургер-меню и визуальный подвал.

## Новая композиция

После заголовочной области размещается единая полноширинная колонка контента:

1. Кнопка «Получить предварительный расчёт» выравнивается по правому краю на широком экране.
2. Первый фрагмент рыбного текста.
3. Широкий серый прямоугольник с примерной пропорцией `16:6`, обозначающий изображение внутри статьи.
4. Продолжение рыбного текста.

Боковое меню и все пять рыбных пунктов удаляются из HTML полностью.

## Адаптив

- На мобильном экране кнопка занимает полную ширину.
- Текстовая колонка и серый прямоугольник занимают всю доступную ширину контейнера.
- Прямоугольник сохраняет пропорции и не создаёт горизонтального переполнения.
- Шапка продолжает использовать существующий бургер.

## Семантика прототипа

- Серый прямоугольник имеет отдельный атрибут `data-production-inline-image` и доступное описание «Место для изображения в тексте».
- Кнопка остаётся элементом `span` с `aria-disabled="true"`.
- Формы, ссылки кнопки и дополнительные интерактивные элементы не добавляются.

## Проверка

- На странице отсутствует `aside` и атрибут `data-production-side-item`.
- Присутствует ровно один встроенный серый прямоугольник между первым и последующим текстовыми фрагментами.
- На десктопе контент занимает ширину общего контейнера.
- На мобильном отсутствует горизонтальное переполнение.
